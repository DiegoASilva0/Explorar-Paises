# 🌎 Mundo em Dados

Um explorador de países desenvolvido com HTML, CSS e JavaScript, utilizando uma API pública para buscar e exibir informações sobre diferentes países.

## 📌 Sobre o projeto

O Mundo em Dados permite pesquisar países e consultar informações como:

- 🌎 Continente
- 🏳️ Bandeira
- 👥 População
- 🏛️ Capital
- 💰 Moeda
- 🗣️ Idioma
- 🔎 Pesquisa por nome
- 🌍 Filtro por continente

O projeto foi desenvolvido como parte do meu aprendizado em JavaScript e consumo de APIs.

## 🚀 Funcionalidades

- Pesquisar países pelo nome
- Filtrar países por continente
- Visualizar informações detalhadas de um país
- Exibir bandeiras dos países
- Exibir população formatada
- Interface responsiva para diferentes tamanhos de tela
- Tratamento básico de erros da API

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Fetch API
- Async/Await
- API REST
- CSS Grid
- CSS Flexbox
